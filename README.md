# Hey, I'm Eden

I build AI agents and the tools around them. I'm curious about what happens **between a model's answer and a finished task**: context, tools, human decisions, and the evidence that it worked.

Currently deep in coding agents, with one foot in runtimes and the other in product delivery. Still happiest when I can look underneath the abstraction.

**Open to AI Agent Engineering roles, including remote.** HKU Computer Science MSc requirements completed; degree conferral expected November 2026.
