# Third-party assets

## Fonts

- [Iosevka](https://github.com/be5invis/Iosevka), bold monospace. Fontsource package `iosevka@5.3.0`, `latin-700-normal.woff2`. [Bundled license](fonts/Iosevka-LICENSE.md).
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), regular and bold. Upstream `fonts/ttf/JetBrainsMono-Regular.ttf` and `fonts/ttf/JetBrainsMono-Bold.ttf`. [Bundled license](fonts/JetBrainsMono-LICENSE.txt).

Original font files are bundled for reproducible editing. Generated graphics use glyph outlines; visitors do not download these font files to display the README.

## Chinese button glyphs

`Buttons-CJK.ttf` is a modified subset of Droid Sans Fallback containing only the glyphs used by the Chinese language/contact buttons. Copyright 2006–2010 Google Corp.; Apache-2.0. [License](fonts/Buttons-CJK-LICENSE.txt) · [Upstream notice](fonts/Buttons-CJK-NOTICE.txt). The subset is outlined into SVGs, just like the Latin fonts.

## Technology icons

[Devicon](https://github.com/devicons/devicon), tag `v2.17.0`, MIT. Fifteen original SVGs are bundled in `vendor/devicon/`. [License](vendor/devicon/LICENSE).

Brand marks identify the tools used. The Rust mark is recolored for visibility in dark mode. No endorsement is implied.

## Preview only

- [github-markdown-css](https://github.com/sindresorhus/github-markdown-css), MIT. [License](vendor/github-markdown-css/LICENSE).
- [Marked](https://github.com/markedjs/marked), `18.0.14`, MIT, invoked through npx for local Markdown rendering.

The preview files are not required for the deployed profile.
